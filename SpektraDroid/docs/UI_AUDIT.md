# 模拟器页面与交互评估

2026-11-07（洛杉矶）／2026-11-08（模拟器北京时间）。评估对象：已安装的 `com.spektralab.android.dev`，1.2-dev / versionCode 3，最新工作站开发包。本轮只做实际操作、截图和评估，未修改应用实现，未重新编译、提交或发布。

## 结论

暖黑、米白和琥珀色形成了统一的暗房风格，值得保留。三个模式的划分正确，导入、拍摄、查看素材、进入工作台、导出、重新编辑原片等主要路径可以走通。

页面还没有达到成熟摄影工具的完成度。主要问题是画面被常驻控件挤压、不同用途的按钮缺少层级、拍摄和导出后的结果反馈不够可靠。横屏问题更明显。建议先解决布局与状态反馈，再扩展功能。

## 环境、范围与边界

- Android 15 / API 35 arm64，`emulator-5554`，1080 × 2400，density 420；检查竖屏和 2400 × 1080 横屏。
- 使用正常界面导入 `AuditSample-Z8.jpg`（1024 × 683），实际拍摄模拟器相机照片，录制并回放演示监看视频，导出 JPEG 并重新打开原片。
- 导入样片来自此前 RAW 验证的处理结果，仅用于布局与流程检查；不用于评价胶片色彩、RAW 精度或预览与成片一致性。
- 监视器使用明确标注“演示模式 · 非实体相机”的调试入口。未连接实体 Sony，不能据此认定 USB 硬件兼容、真实取景帧率或长录稳定性。
- 本轮未观察到新增崩溃。崩溃缓冲区中有模拟器时间 10:02:24 的旧初始化错误，早于当前安装时间 11:03:21；本轮截图操作约为 12:14–12:28。该历史问题的修复已在 `WORKSTATION_VALIDATION.md` 记录。

## 问题与修复方向

P1 表示影响核心拍摄／编辑任务，应优先处理；P2 表示流程可用但增加理解或操作成本。

| 编号 | 优先级 | 实际观察 | 影响与建议 |
|---|---|---|---|
| A1 | P1 | 工作台竖屏查看区约 703 px，占整屏约 29%；横屏查看区高度约 206 px。参数面板、素材条和底部导航同时常驻。 | 照片很难成为视觉中心。竖屏改为可收起／可调高度的参数面板；横屏把导航收至侧边，素材默认缩为最近一张或可展开胶片条。保留照片完整构图，不靠裁切填满屏幕。 |
| A2 | P1 | 相机展开胶片参数后，素材缩略图只露出约 12 px 的窄条；横屏默认控制区也只能看到素材标题。快门仍能点击。 | 拍完难以立即确认结果。把最新照片缩略图固定在快门附近；完整素材条按需展开，与参数列表分开布局。 |
| A3 | P1 | 导出成功后，素材数从 21 变为 22，但新成片位于缩略条最左侧屏外，只露出约 11 px。此前导入也出现相同现象。 | 用户看不到刚生成的结果。新增素材后显示最新项目，或提供明确“已保存／查看成片”入口；用户主动浏览旧素材时可用“有新素材”提示，避免突然打断。 |
| A4 | P1 | 监视器展开胶片参数后，“收起胶片参数”按钮随内容移动到屏外。参数面板和外层页面均需滚动。 | 收起不容易发现，调整时取景区还会进一步缩小。面板开关固定在面板标题处；控制面板只保留一个主要滚动层。 |
| A5 | P1 | 录制中直接点底部工作台，立即结束并保存视频、断开连接，没有事前提示。返回监视器后显示“已断开连接”，同时仍显示旧取景画面和约 26.8 fps。 | 容易误停录制，也容易把旧帧误认成实时画面。录制中切换模式需明确“结束并保存后离开”的选择；停止后将帧率归零／隐藏，并在旧帧上覆盖“连接已断开 · 最后一帧”。 |
| A6 | P2 | 相机的“标准”“拍摄参数”“胶片参数”“胶片预览”采用相同按钮外观，分别代表模式、面板开关和功能开关；可同时高亮。“拍摄”还同时用于工作台胶片曝光标签、相机入口和快门。 | 控件外观不能传达操作类型。拍摄模式单独分组，参数用工具入口，预览用带开关状态的控件；胶片中的“拍摄”改为“底片曝光”等明确名称，区分相机曝光与胶片曝光。 |
| A7 | P2 | 空工作台已经展示大块胶片参数列表，空状态中的“拍摄”按钮被下面板截住。监视器未连接时先展示旧素材，再显示长篇连接说明和检测入口。 | 首次进入时主任务不突出。工作台空状态突出导入与最近项目；监视器空状态优先显示连接状态、检测按钮和简短步骤，详细线材／相机设置放入展开帮助。 |
| A8 | P2 | 对 1024 × 683 小图，导出对话框的 2048、3072、4096 和完整尺寸选项均显示同样输出尺寸，并始终展示 16 GB 内存建议。 | 用户需在结果相同的选项间做选择。按源图生成有意义的尺寸选项，合并重复项；全尺寸高内存说明主要出现在需要该能力的大图场景。保留大 RAW 的内存检查。 |
| A9 | P2 | 监看录制状态只有“录制中”，没有累计时长。技术说明常驻，HDR 不支持说明使用 11 sp 暗灰文字。 | 难以确认录制进展，户外阅读负担较大。增加录制时长，重要状态提升对比；解释性长文收至帮助。`TextFaint` 对 `Panel` 的静态颜色对比约 3.20:1，低于普通小字常用的 4.5:1 标准；这只是颜色检查，不代表完整无障碍审计。 |

## 素材与配方的进一步完善

素材库支持搜索、来源／类型筛选、详情、前后翻张和返回原片，基本结构合理。当前列表更像文件管理器：长文件名占据多行，照片拍摄时间、尺寸、时长等有用信息不足。可以把日期／时间和来源作为主要信息，完整文件名在详情保留，避免直接裁掉长文件名。来源中的“相机传输”同时包含监看录屏，建议区分相机原片与监看视频，便于理解。

照片详情默认显示原片，胶片效果要进工作台才显示，虽然有文字解释，仍建议提供明显的“原片／胶片预览”状态，减少“刚才滤镜怎么没了”的疑问。当前详情未提供直接分享成片或视频的入口，后续可补齐保存后分享路径。

配方弹窗的保存、应用、改名、移除都能看懂，但配方之间只有文字区别，没有效果参考、当前应用标识或“更新当前配方”动作。保存又打开第二层弹窗，操作略重。建议用一层配方面板容纳预览、保存和命名，更新已有配方时提供明确覆盖选择。

以上为设计建议；本轮没有验证配方覆盖、分享、撤销重做等尚未实现的功能。

## 下一轮建议验收顺序

1. 先修 A1–A4：工作台照片足够大；相机最近照片与监视器收起按钮始终可达；导出后立即看到新成片。
2. 修 A5：录制中切换模式有清楚选择，断开后不会将旧画面表现为实时流；补录制时长。
3. 统一控件语义、空状态和尺寸选择，处理 A6–A9；再检查横屏与较大系统字体。
4. 完善编辑撤销／重做、裁切旋转、成片／视频分享和配方更新。它们比继续堆叠拍摄模式更有助于完成现有工作流程。

重排后的每个页面需再次实际截图检查；不能把编译成功或控件存在当作布局通过。实体手机上的强光可读性、手持操作、Sony 连接与断线仍需另行实测。
