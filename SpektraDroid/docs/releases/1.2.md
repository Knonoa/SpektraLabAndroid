# SpektraLab for Android 1.2

## 中文

本版为非官方安卓移植，新增胶片边框、日期后背与拍摄页，并扩展高精度 RAW / TIFF 导入。

- Film Edge：移植桌面版片门、齿孔、型号、帧号、雾化和漏光，在底片曝光阶段参与胶片处理。
- Date Back：液晶 / 点阵日期与 EXIF 快门、光圈等拍摄信息。
- CameraX 拍摄页、实时胶片预览、逻辑 / 物理镜头参数及厂商公开的 HDR / 夜景能力，支持调用系统相机。
- 使用处理后的取景画面做胶片预览，修复普通模式独立分析流造成的颜色与明暗偏差；设备仍可能存在预览与照片处理差别。
- DNG、ARW、NEF、CR2、CR3 和 TIFF 以原生线性浮点图像进入胶片引擎；RAW 的上游转换为 LibRaw 16 位 compatible 策略，显示和 JPEG 为 8 位。
- 固定 LibRaw `0.23.0-Snapshot202611`，支持本轮实测的新索尼 ARW6、尼康 HE/HE*；修复大像素 RAW 同时保留多份完整缓冲的内存问题。
- 根目录 README 已按安卓工程重写为中英文版本，补充来源、构建、测试与限制。

### 安装

Android 8.0+，通用 APK 包含 arm64-v8a / armeabi-v7a / x86_64。正式包名 `com.spektralab.android`，versionCode `3`，启用代码压缩和资源精简。

**1.1 用户先备份设置并卸载旧版。** 原版调试签名私钥不可用，本版开始使用独立发布密钥，无法直接覆盖旧签名；卸载会清除应用设置和缓存。`.dev` / `.usb` 开发版可并存。后续升级须沿用 1.2 密钥。

### 验证与已知范围

真实样片覆盖 Sony A7R V / A7R VI / A1 / A1 II / A7 V / A7 IV、Nikon Z8 / Z9 / Z6 III，另含旧机型 ARW、NEF、Canon CR2/CR3 和 DNG 回归。样片来源与逐文件 SHA 见 [raw-fixtures.json](../raw-fixtures.json)，模式与尺寸见 [RAW_VALIDATION.md](../RAW_VALIDATION.md)。

已验证 640/1024 像素两级解码和胶片 JPEG 输出，不代表全部 RAW 压缩组合或原始全分辨率导出。HDR/夜景、物理镜头访问由厂商开放能力决定；扩展会话胶片预览不可用。半格双联和交互裁切尚未移植。当前界面以中文为主。

## English

This unofficial Android port adds Film Edge, Date Back and an in-app capture page, and expands high-precision RAW / TIFF import.

- Ported film gates, perforations, stock markings, frame numbers, fog and light leaks into the negative exposure/development pipeline.
- LCD-style / dot-matrix dates and available EXIF shooting data.
- CameraX capture, live film preview, public logical/physical camera information, manufacturer HDR/night capabilities and system-camera handoff.
- Live film preview now uses the processed viewfinder image, addressing colour/exposure differences caused by a separate analysis stream in standard mode. Device-specific preview/capture differences can remain.
- Native linear float image input for DNG, ARW, NEF, CR2, CR3 and TIFF. RAW uses LibRaw’s 16-bit compatible conversion before float processing; display and JPEG are 8-bit.
- Pinned official LibRaw development snapshot for the tested new Sony ARW6 and Nikon HE/HE* samples; reduced simultaneous full-size RAW buffers to fix the tested high-resolution import memory failure.
- Android-focused English and Chinese READMEs, with build instructions, provenance and explicit validation limits.

### Installation

Android 8.0+, universal arm64-v8a / armeabi-v7a / x86_64 APK. Production ID `com.spektralab.android`, version code `3`, with R8 and resource shrinking enabled.

**Back up settings and uninstall 1.1 first.** The old debug signing key is unavailable; 1.2 establishes a dedicated release key, so Android cannot update the old certificate in place. Uninstalling removes app settings/cache. Developer `.dev` / `.usb` builds can coexist. Future releases must retain the 1.2 key.

### Validation scope

Public, checksum-verified samples cover Sony A7R V / A7R VI / A1 / A1 II / A7 V / A7 IV and Nikon Z8 / Z9 / Z6 III, plus older ARW/NEF/Canon CR2/CR3/DNG regression samples. See [fixture provenance](../raw-fixtures.json) and [mode-specific results](../RAW_VALIDATION.md).

Validation covers 640/1024 px decode and film JPEG output, not all RAW compression variants or full-resolution output. HDR/night and physical camera access depend on manufacturer exposure of those capabilities. Live film preview is unavailable in extension sessions. Half-frame pairing and interactive cropping are not implemented. The current UI is primarily Chinese.
